# SO-101 + AmazingHand: 손목 회전 기반 측면 파지 / 두 테이블 운반

## 실행
```bash
python -m pip install -r requirements.txt
python side_transfer.py --viewer
```
창 없는 Linux에서 기록:
```bash
MUJOCO_GL=egl python side_transfer.py --video
```
결과: results/side_transfer.mp4, final.png, side_transfer.json. 성공 종료코드0, 실패2.

## 구현
- 손바닥 법선을 수평 접선 방향으로, 손의 길이축을 수평 반경 방향으로 맞춥니다. 손목 roll을 사용하므로 높은 테이블에 손을 아래에서 세워 넣던 시험과 다릅니다.
- 두 상판 높이60mm, 크기130×100mm. 중심은 (.30,-.08), (.30,+.08)m, 사이 간격60mm. 베이스는 기존 높이52.4mm에 고정.
- 손잡이 없는 열린 컵 근사: 외경약50mm, 높이120mm, 질량60g. 기본 초기 위치(.26,-.08,.122)m. 원본 물체명 demo_cube/cube_collision은 API 호환을 위해 유지.
- 팔/손 초기 상태를 설정한 뒤부터는 손과 물체의 실제 접촉/마찰로 파지·이동. 물체 weld, mocap, 강제 운반 force 없음.
- 손가락 1~3은 기본 pair(+0.5,-0.5), 엄지는(+1.5,-1.5). 열 때는 모두(-0.8,+0.8). 각도rad.
- 5축 IK는 position + palm normal + hand axis를 함께 근사합니다. 도달 오차는 결과 JSON 참조. 모든 요청 자세가 정확히 구현되는 것은 아니며 경로 충돌을 보장하는 planner가 아닙니다.
- 목적 손끝 명령은 파지 시 cup-to-palm 상대 변환과 회전 방향을 반영합니다. release 후 측면/위로 손을 빼고2초 정착을 확인합니다.

## 검증
success는 컵 상승>15mm, 최종 컵 중심 목적(.26,+.08)에서 x±30/y±25mm, upright_cos>0.95, table2접촉, 손 접촉 없음 조건입니다. 최종 속도는 현재 성공식에 포함하지 않으므로 결과는 해당 조건의 제한된 성공 판정입니다.
기준 시험에서 약28.5mm 상승, 최종위치약(.26346,.07888,.11989)m, upright_cos≈0.99999993, table2만 접촉. 동일조건 재실행 확인. 다양한 컵/배치에 대한 성공률은 측정하지 않음.

## 시뮬레이션 가정
손 모터 토크한계±0.3Nm와 접촉마찰3.0은 조정된 가정값이며 실측값이 아닙니다. 기존 모델의 질량/관성 추정, convex 접촉근사, 로봇내부 자기충돌 비활성, 베이스 고정을 유지합니다. 실물 검증 결과로 해석하지 마세요.

## VLA-Adapter-Pro 연결
현재 동작은 IK+수작업 파지 정책이며 VLA 미연결입니다.
1. 실제 체크포인트의 관측 입력과 action 차원·좌표계·단위·정규화·chunk 실행주기를 확인.
2. 실제 출력의 역정규화 및 좌표 변환을 담당하는 Action Adapter 구현. Cartesian출력이면 ik를 호출하고, joint출력이면 관절매핑을 사용. 임의로 서로 바꾸면 안 됩니다.
3. gripper값을 위 손가락 정책에 매핑. side_transfer.py의 하드코딩 경로를 VLA의 행동 chunk로 교체. 영상·명령·관절 상태는 모델에 실제로 전달해야 함.
4. 도달/자세 잔차·관절/속도 제한을 검사해 불가능 명령을 거부하고 실행 후 영상을 재관찰.
5. 정상작업을 평가하고 부족하면 성공시연으로 미세조정. 그다음 Phase A 복구명령 우선처리와 Phase B 재추론 판정 연결.
정상 시연코드가 성공했다는 것은 VLA 무학습 호환을 검증했다는 뜻이 아닙니다.

공식 원본 라이선스·출처는 provenance 폴더 참조.
